
# KyntricAI

### Learn. Code. Build. Master.

KyntricAI is an AI-powered programming education platform designed to teach everyone how to code, from complete beginners to advanced developers.

## Core Features

- Comprehensive programming courses
- Interactive coding lessons
- AI-powered coding tutor
- Browser-based code playground
- Programming challenges and quizzes
- Video lessons and tutorials
- Personalized learning paths
- Student accounts and profiles
- XP, achievements and certificates
- AI-assisted course creation

## Learning Categories

- Web Development
- Programming Languages
- Game Development
- Artificial Intelligence
- Machine Learning
- Databases
- Computer Science
- Cybersecurity

## Technology

- HTML, CSS and JavaScript
- GitHub Pages
- Supabase
- AI model integrations
- Monaco Editor

## Platform Model

Free educational content with optional premium features.

Currently in Phase 1: Foundation.
